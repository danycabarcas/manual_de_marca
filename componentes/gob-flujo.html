Línea de tiempo y pasos

gob-linea-tiempo y gob-pasos: historial de trámites y asistentes por pasos, accesibles y con ejemplos para copiar.

Historiales y asistentes: gob-linea-tiempo para mostrar qué pasó con un trámite o ticket y gob-pasos para formularios en varios pasos.

01. Instalación (todo lo que hay que cargar)

URL base:
Instalación
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<!-- ② Use la etiqueta de cualquier ejemplo de esta página -->

Funcionan igual en HTML, Angular (CUSTOM_ELEMENTS_SCHEMA), React y Next.js (solo cliente). Sin dependencias: gob.js descarga cada componente solo si está en la página.

3 · Pasos (asistente)

Indicador de progreso que muestra el contenido del paso actual (slot="paso0", paso1…). Usted controla los botones con siguiente() / anterior() y valida antes de avanzar; error marca un paso.

Revise y confirme.
Ver código completo (copiar y pegar)
ps1.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<gob-pasos id="ps1" pasos='[{"titulo":"Sus datos","descripcion":"Identificación"},{"titulo":"Su solicitud"},{"titulo":"Confirmar"}]' clicable>
  <div slot="paso0"><label>Nombre <input id="ps1-nombre" placeholder="Escriba su nombre"></label></div>
  <div slot="paso1"><label>Asunto <input placeholder="¿Qué necesita?"></label></div>
  <div slot="paso2"><gob-alerta tipo="exito" titulo="Todo listo">Revise y confirme.</gob-alerta></div>
</gob-pasos>
<div style="display:flex;gap:.5rem;margin-top:1rem"><button type="button" id="ps1-atras">Atrás</button><button id="ps1-sig">Siguiente</button></div>
<script type="module">
  const p = document.getElementById('ps1');
  document.getElementById('ps1-atras').onclick = () => p.anterior();
  document.getElementById('ps1-sig').onclick = () => {
    if (p.actual === 0 && !document.getElementById('ps1-nombre').value.trim()) { p.error = 0; return gob.toast({ tipo: 'aviso', titulo: 'Escriba su nombre' }); }
    p.error = -1; p.actual === p.total - 1 ? gob.toast({ tipo: 'exito', titulo: 'Enviado' }) : p.siguiente();
  };
  p.addEventListener('gob-paso-cambio', (e) => console.log(e.detail));   // { actual, id, primero, ultimo }
</script>

03. Referencia

gob-linea-tiempo

Propiedad / eventoDescripción
eventos (JSON)[{ fecha, titulo, descripcion, autor, icono, tipo }] con tipo: primario, info, exito, aviso, peligro, neutro.
orientacionvertical (defecto) | horizontal.
alternarLados alternos (≥ 640 px).
invertirMás reciente primero.
slot="e0", "e1"…Contenido extra dentro de cada evento.

gob-pasos

Propiedad / eventoDescripción
pasos (JSON)[{ id?, titulo, descripcion?, icono? }]. El slot de cada paso es id o paso<n>.
actualÍndice del paso (desde 0).
vertical, clicableDisposición vertical; clic en pasos ya alcanzados.
errorÍndice del paso con error (−1 = ninguno).
siguiente() · anterior() · ir(n) · totalControl programático.
gob-paso-cambio{ actual, id, primero, ultimo }
