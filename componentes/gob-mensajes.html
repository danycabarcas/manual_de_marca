Alertas, modales y toasts

gob-alerta, gob-modal, gob.toast() y gob.confirmar(): mensajes y diálogos accesibles con ejemplos para copiar.

Alertas, diálogos modales, notificaciones (toasts) y confirmaciones listos para cualquier framework. Todos son accesibles: foco atrapado y devuelto, role correcto, anuncio a lectores de pantalla y prefers-reduced-motion.

01. Instalación (todo lo que hay que cargar)

URL base:
Instalación mínima
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->

2 · Modal con formulario

Basado en <dialog> nativo: atrapa el foco, se cierra con Esc o clic en el fondo, bloquea el scroll y devuelve el foco al botón que lo abrió. Slot pie para los botones.
Ver código completo (copiar y pegar)
m1.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<button class="mg-btn" id="abrir1">Nuevo trámite</button>

<gob-modal id="modal1" titulo="Nuevo trámite" tipo="info">
  <div style="display:grid;gap:.75rem">
    <div><label class="mg-label" for="asunto1">Asunto</label><input class="mg-input" id="asunto1" placeholder="Describa su solicitud"></div>
    <div><label class="mg-label" for="mun1">Municipio</label><select class="mg-select" id="mun1"><option>Santa Marta</option><option>Ciénaga</option><option>Fundación</option></select></div>
  </div>
  <button slot="pie" class="mg-btn mg-btn--secondary" id="cancelar1">Cancelar</button>
  <button slot="pie" class="mg-btn" id="guardar1">Guardar</button>
</gob-modal>

<script type="module">
  const m = document.getElementById('modal1');
  document.getElementById('abrir1').onclick = () => m.abrir();
  document.getElementById('cancelar1').onclick = () => m.cerrar();
  document.getElementById('guardar1').onclick = () => { m.cerrar(); gob.toast({ tipo: 'exito', titulo: 'Trámite creado' }); };
  m.addEventListener('gob-modal-cerrar', (e) => console.log('cerrado por:', e.detail.motivo));   // boton | esc | fondo | api
</script>

3 · Confirmación (gob.confirmar) y tipos

gob.confirmar() devuelve una promesa: true si el usuario acepta. Sirve para cualquier acción destructiva sin escribir HTML.

Ver código completo (copiar y pegar)
m2.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<div class="mg-row">
  <button class="mg-btn mg-btn--danger" id="del2">Eliminar registro</button>
  <button class="mg-btn mg-btn--secondary" id="pub2">Publicar</button>
</div>
<p id="res2" class="mg-help" aria-live="polite"></p>

<script type="module">
  document.getElementById('del2').onclick = async () => {
    const ok = await gob.confirmar({ titulo: 'Eliminar registro', mensaje: 'Esta acción no se puede deshacer.', tipo: 'peligro', textoConfirmar: 'Sí, eliminar' });
    document.getElementById('res2').textContent = ok ? 'Confirmado: se eliminó.' : 'Cancelado.';
  };
  document.getElementById('pub2').onclick = async () => {
    const ok = await gob.confirmar({ titulo: '¿Publicar?', mensaje: 'El documento será visible para toda la ciudadanía.', tipo: 'aviso', textoConfirmar: 'Publicar' });
    if (ok) gob.toast({ tipo: 'exito', titulo: 'Publicado' });
  };
</script>

4 · Tamaños y modal estático

Tamaños sm · md · lg · xl · pantalla. Con estatico no se cierra con Esc ni con clic afuera (procesos que no deben interrumpirse).

Contenido amplio: tablas, formularios largos o vistas previas de documentos. El cuerpo tiene su propio scroll si excede la altura de la pantalla.

No cierre esta ventana hasta que termine el proceso.

5 · Toasts (notificaciones)

Se apilan, se pausan al pasar el cursor, se pueden cerrar y admiten una acción (p. ej. «Deshacer»). duracion: 0 las deja fijas. role="alert" para errores.

Ver código completo (copiar y pegar)
n1.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<div class="mg-row">
  <button class="mg-btn mg-btn--secondary" id="ok4">Éxito</button>
  <button class="mg-btn mg-btn--secondary" id="inf4">Info</button>
  <button class="mg-btn mg-btn--secondary" id="av4">Aviso</button>
  <button class="mg-btn mg-btn--secondary" id="er4">Error fijo</button>
  <button class="mg-btn mg-btn--secondary" id="un4">Con «Deshacer»</button>
</div>

<script type="module">
  const $ = (id) => document.getElementById(id);
  $('ok4').onclick = () => gob.toast({ tipo: 'exito', titulo: 'Guardado', mensaje: 'Los cambios se guardaron.' });
  $('inf4').onclick = () => gob.toast('Hay una nueva versión del manual.');                  // forma corta
  $('av4').onclick = () => gob.toast({ tipo: 'aviso', titulo: 'Conexión lenta', duracion: 8000 });
  $('er4').onclick = () => gob.toast({ tipo: 'peligro', titulo: 'Error de red', mensaje: 'No se pudo contactar al servidor.', duracion: 0 });
  $('un4').onclick = () => gob.toast({ tipo: 'neutro', titulo: 'Trámite archivado', accion: { etiqueta: 'Deshacer', alClic: () => gob.toast({ tipo: 'exito', titulo: 'Restaurado' }) } });
  // Posición: document.querySelector('gob-toasts').posicion = 'arriba-derecha'  (abajo-derecha | abajo-izquierda | arriba-izquierda | arriba-centro)
</script>

03. Referencia

ComponenteEventos y API
<gob-alerta>Atributos: tipo (info, exito, aviso, peligro, neutro), titulo, cerrable, icono. Evento: gob-alerta-cerrar. Slots: por defecto y acciones.
<gob-modal>Atributos: abierto, titulo, tam (sm, md, lg, xl, pantalla), tipo (normal, info, exito, aviso, peligro), icono, cerrable, estatico. Métodos: abrir(), cerrar(motivo?). Eventos: gob-modal-abrir, gob-modal-cerrar (detail.motivo: boton, esc, fondo, api). Slots: por defecto y pie.
gob.toast(opciones | texto){ tipo, titulo, mensaje, duracion = 5000, accion: { etiqueta, alClic } }. Devuelve una promesa con el id. El contenedor <gob-toasts> se crea solo; posicion y max son configurables.
gob.confirmar(opciones | texto){ titulo, mensaje, tipo, textoConfirmar, textoCancelar } → Promise<boolean>.

04. Accesibilidad

  • Modal: elemento <dialog> nativo con aria-labelledby; el foco queda dentro, Esc cierra (salvo estatico) y el foco vuelve al botón que lo abrió.
  • Toast y alerta: role="status" (cortés) o role="alert" (peligro y aviso); los toasts se pausan con el cursor y con el foco.
  • Todos los botones tienen nombre accesible y foco visible; las animaciones se desactivan con prefers-reduced-motion.
