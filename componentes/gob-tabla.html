gob-tabla

Tabla de datos con búsqueda, filtros, orden, selección, acciones, paginación, totales y exportación. Ejemplos listos para copiar.

Tabla de datos accesible, basada en el elemento nativo <table>: búsqueda, filtros por columna, orden, selección, acciones por fila y masivas, paginación (local o de servidor), totales, columnas visibles, exportar a Excel (CSV), copiar, imprimir y vista de tarjetas en móvil. Funciona igual en HTML plano, Angular, React, Vue o Next.js. Configúrela visualmente en el Estudio de tablas →

01. Cuándo usarla y cuándo no

✔ Usar para
Listados administrativos, bandejas, reportes y catálogos en cualquier framework; hasta unas decenas de miles de filas en memoria, y sin límite con modo-servidor.
✘ No usar para
Hojas de cálculo con edición de celdas, agrupación/pivote o millones de filas en el cliente (use AG Grid Community) ni para maquetar layouts. Para Angular puede usar también p-table de PrimeNG con el preset oficial.

Sin internet o en intranet

Descargue gob-cdn-v1.zip, descomprímalo en su servidor y use esa carpeta como URL base: incluye los scripts, la tipografía Montserrat, los datos geográficos y los íconos. No hay llamadas a servicios externos.

5 · Modo servidor (paginación, orden y búsqueda en su API)

Con modo-servidor la tabla no procesa nada: emite gob-tabla-consulta y usted responde con datos y totalFilas. Aquí la API se simula con un retardo.

Ver código completo (copiar y pegar)
t5.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<gob-tabla id="t5" titulo="Trámites (servidor)" modo-servidor tamano-pagina="5"></gob-tabla>

<script type="module">
  const t = document.getElementById('t5');
  const BD = await fetch('https://TU-HOST/manual_de_marca/cdn/v1/datos/ejemplo-tramites.json').then((r) => r.json());           // simula su base de datos
  t.columnas = [{ campo: 'radicado', titulo: 'Radicado', nowrap: true }, { campo: 'asunto', titulo: 'Asunto' }, { campo: 'municipio', titulo: 'Municipio' }, { campo: 'dias', titulo: 'Días', tipo: 'numero' }];

  t.addEventListener('gob-tabla-consulta', async (e) => {
    const { pagina, tamano, orden, busqueda } = e.detail;
    t.cargando = true;
    // ← REAL: const r = await fetch(`/api/tramites?pagina=${pagina}&tamano=${tamano}&q=${busqueda}&orden=${orden?.campo}&dir=${orden?.dir}`).then(r => r.json());
    await new Promise((ok) => setTimeout(ok, 450));
    let f = BD.filter((x) => !busqueda || JSON.stringify(x).toLowerCase().includes(busqueda.toLowerCase()));
    if (orden) f.sort((a, b) => (a[orden.campo] > b[orden.campo] ? 1 : -1) * (orden.dir === 'asc' ? 1 : -1));
    t.totalFilas = f.length;                          // total de resultados (no de la página)
    t.datos = f.slice((pagina - 1) * tamano, pagina * tamano);
    t.cargando = false;
  });
</script>

05. Integración con una API NestJS

API NestJS
// NestJS + Prisma — endpoint para <gob-tabla modo-servidor>
@Get('tramites')
async listar(@Query() q: { pagina?: string; tamano?: string; q?: string; orden?: string; dir?: 'asc' | 'desc' }) {
  const take = Math.min(Number(q.tamano ?? 10), 100), skip = (Number(q.pagina ?? 1) - 1) * take;
  const where = q.q ? { OR: [{ asunto: { contains: q.q, mode: 'insensitive' } }, { radicado: { contains: q.q } }] } : {};
  const [datos, total] = await this.prisma.$transaction([
    this.prisma.tramite.findMany({ where, skip, take, orderBy: q.orden ? { [q.orden]: q.dir ?? 'asc' } : { fecha: 'desc' } }),
    this.prisma.tramite.count({ where }),
  ]);
  return { data: datos, meta: { total, pagina: Number(q.pagina ?? 1), tamano: take } };
}

Slots, partes y variables

Slots: herramientas (botones propios en la barra) y vacio. Partes: tabla, barra, paginacion. Tipografía: --gob-fuente.

07. Accesibilidad

  • Tabla HTML nativa con caption, scope y aria-sort en los encabezados ordenables; los botones de orden, filtros, acciones y paginación son controles reales con foco visible.
  • Cada casilla y botón de fila tiene nombre propio («Seleccionar R-2026-01000», «Editar: R-2026-01000»); el total de resultados se anuncia en una región aria-live.
  • La región de desplazamiento es enfocable por teclado; en móvil la vista de tarjetas conserva las etiquetas de cada dato; no se transmite información solo con color (las insignias llevan texto).
