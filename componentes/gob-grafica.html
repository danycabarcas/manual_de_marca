gob-grafica

Gráficas con la identidad visual: barras, líneas, áreas, torta, dona, radar, indicador, mapa de calor, treemap y sankey.

Gráficas con la identidad visual, basadas en Apache ECharts (carga perezosa): 11 tipos, paleta y tema de la Gobernación, alternativa accesible en texto y exportación a PNG/CSV. Configúrela visualmente en el Estudio de gráficas →

02. Cuándo usarla y cuándo no

✔ Usar para
Indicadores, tendencias, distribuciones, comparativos y tableros en cualquier framework o HTML plano. Siempre con la paleta institucional y accesible.
✘ No usar para
Más de ~8 series en una misma gráfica, tortas con muchas categorías (use barras), ni analítica estadística avanzada. Para tablas de datos use PrimeNG/gob-tabla.

03. Instalación

URL base:
HTML plano (sin build)
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<gob-grafica id="g" tipo="barras" titulo="Casos por municipio" etiquetas></gob-grafica>

<script type="module">
  const g = document.getElementById('g');
  g.datos = [{ nombre: 'Santa Marta', valor: 120 }, { nombre: 'Ciénaga', valor: 80 }];
  g.addEventListener('gob-grafica-click', (e) => console.log(e.detail));
</script>
Angular (CUSTOM_ELEMENTS_SCHEMA)
// index.html:  <script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
  selector: 'app-grafica', standalone: true, schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<gob-grafica tipo="dona" titulo="Por subregión" [datos]="datos"
               (gob-grafica-click)="alClic($event)"></gob-grafica>`,
})
export class GraficaComponent {
  datos = [{ nombre: 'Norte', valor: 420 }, { nombre: 'Sur', valor: 180 }];
  alClic(e: Event) { console.log((e as CustomEvent).detail); }
}
React / Next.js
'use client'; // Next.js: solo cliente
import { useEffect, useRef } from 'react';

export default function Grafica({ datos }) {
  const ref = useRef(null);
  useEffect(() => { import(/* webpackIgnore: true */ 'https://TU-HOST/manual_de_marca/cdn/v1/gob.js'); }, []);
  useEffect(() => { if (ref.current) ref.current.config = { tipo: 'lineas', suave: true, datos }; }, [datos]);
  return <gob-grafica ref={ref} />;
}

Peso

El bundle base (gob.js + CSS) pesa ≈ 25 KB gzip. ECharts (≈ 284 KB gzip, solo los tipos usados) se descarga únicamente cuando aparece la primera gráfica; una página con solo mapa o con solo CSS no lo carga. Componente suelto: /cdn/v1/components/gob-grafica.js.

06. Integración con una API NestJS

La API devuelve los datos ya agregados; el componente solo dibuja. Formato de respuesta recomendado: { data, meta }.

API NestJS → gráfica
// NestJS + Prisma: serie mensual lista para <gob-grafica>
@Get('radicados-por-mes')
async porMes() {
  const filas = await this.prisma.$queryRaw<{ mes: string; estado: string; total: bigint }[]>`
    SELECT to_char(fecha, 'Mon') AS mes, estado, COUNT(*) AS total FROM radicados GROUP BY 1, 2`;
  const meses = [...new Set(filas.map((f) => f.mes))];
  const estados = [...new Set(filas.map((f) => f.estado))];
  return { data: {
    categorias: meses,
    series: estados.map((e) => ({ nombre: e, valores: meses.map((m) => Number(filas.find((f) => f.mes === m && f.estado === e)?.total ?? 0)) })),
  }, meta: { actualizado: new Date().toISOString() } };
}

// Frontend:  grafica.datos = (await fetch('/api/radicados-por-mes').then(r => r.json())).data;

07. Accesibilidad

  • Contenedor con role="img" y nombre accesible (título + descripción) y tabla de datos equivalente oculta visualmente para lectores de pantalla.
  • Descripción automática de ECharts (aria) y opción patrones para no depender solo del color.
  • prefers-reduced-motion desactiva la animación. Los tooltips y etiquetas repiten los valores; el CSV es la alternativa para analizar los datos.
  • La paleta institucional alterna tonos claros y oscuros contiguos; para texto sobre las series use etiquetas solo en gráficas apiladas oscuras o con la paleta azules.
