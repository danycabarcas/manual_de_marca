Selector, fecha y archivos

gob-selector, gob-fecha y gob-archivos: campos avanzados con búsqueda, calendario en español y carga de archivos.

Campos avanzados de formulario: gob-selector (búsqueda y multiselección), gob-fecha (calendario y rango) y gob-archivos (arrastrar y soltar). Participan en <form> y son accesibles con teclado.

01. Instalación (todo lo que hay que cargar)

URL base:
Instalación
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<!-- ② Use la etiqueta de cualquier ejemplo de esta página -->

Funcionan igual en HTML, Angular (CUSTOM_ELEMENTS_SCHEMA), React y Next.js (solo cliente). Sin dependencias: gob.js descarga cada componente solo si está en la página.

02. Ejemplos (cada uno con su código completo)

1 · Selector con búsqueda

Escriba para filtrar (sin tildes), flechas + Enter para elegir, Esc para cerrar. Participa en <form> con name y requerido.

Ver código completo (copiar y pegar)

<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<gob-selector id="sl1" etiqueta="Municipio" placeholder="Busque un municipio" name="municipio" limpiable

3 · Fecha y rango de fechas

Calendario en español con teclado (flechas, PageUp/PageDown, Home/End, Esc). valor es ISO 2026-10-14; en rango es inicio/fin. min y max deshabilitan días.

Ver código completo (copiar y pegar)
fe1.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<div style="display:flex;gap:1rem;flex-wrap:wrap;align-items:start">
  <gob-fecha id="fe1" etiqueta="Fecha de radicación" valor="2026-10-14" min="2026-01-01" max="2026-12-31" style="width:16rem"></gob-fecha>
  <gob-fecha id="fe2" rango etiqueta="Periodo" placeholder="Elija un periodo" style="width:20rem"></gob-fecha>
</div>
<script type="module">
  document.getElementById('fe2').addEventListener('gob-fecha-cambio', (e) => console.log(e.detail));   // { valor, inicio, fin }
</script>

4 · Subir archivos

Arrastre o haga clic; valida tipo y tamaño y marca los rechazados. Con progreso(nombre, %) muestra el avance de su carga real (XHR/fetch).

Ver código completo (copiar y pegar)
ar1.html
<!-- ① Dependencias: TODO lo que hay que cargar (una vez por página) -->
<link rel="stylesheet" href="https://TU-HOST/manual_de_marca/cdn/v1/gob.css">
<script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>

<gob-archivos id="ar1" multiple accept=".pdf,.jpg,.png" max-mb="2" max-archivos="4" name="anexos"></gob-archivos>
<button type="button" id="ar1-enviar" style="margin-top:.75rem">Enviar (simulado)</button>
<script type="module">
  const a = document.getElementById('ar1');
  a.addEventListener('gob-archivos-cambio', (e) => console.log(e.detail.archivos, e.detail.rechazados));
  document.getElementById('ar1-enviar').onclick = () => a.archivos.forEach((f) => { let p = 0; const t = setInterval(() => { a.progreso(f.name, (p += 20)); if (p >= 100) { clearInterval(t); gob.toast({ tipo: 'exito', titulo: f.name + ' enviado' }); } }, 250); });
</script>

03. Referencia

gob-selector

Propiedad / eventoDescripción
opciones (JSON)Cadenas u objetos { valor, etiqueta, grupo?, descripcion?, icono?, deshabilitada? }.
valorTexto (simple) o arreglo (múltiple); también atributo con comas.
multiple, buscable, limpiableMultiselección, cuadro de búsqueda (defecto sí) y botón limpiar.
placeholder, etiqueta, name, requerido, deshabilitado, invalido, max-chipsTextos, formulario y estados.
gob-selector-cambio{ valor, opciones }
abrir() · limpiar() · seleccionMétodos y getter.

gob-fecha

Propiedad / eventoDescripción
valorISO aaaa-mm-dd o inicio/fin con rango.
min, maxLímites ISO.
placeholder, etiqueta, name, limpiable, deshabilitado, invalidoTexto y estados.
gob-fecha-cambio{ valor, inicio, fin }

gob-archivos

Propiedad / eventoDescripción
multiple, accept, max-mb, max-archivosOpciones de validación (accept: extensiones o tipos MIME).
etiqueta, ayuda, name, deshabilitadoTextos y formulario.
archivosGetter: archivos válidos (File[]).
gob-archivos-cambio{ archivos, rechazados }
progreso(nombre, pct) · quitar(i) · limpiar()Métodos.
