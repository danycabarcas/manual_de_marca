gob-mapa-magdalena

Mapa interactivo del Magdalena por municipios (DIVIPOLA): coropleta, subregiones, categorías, marcadores, rutas animadas y efectos.

Mapa interactivo del departamento del Magdalena con sus 30 municipios, identificados por código DIVIPOLA. Es un Web Component (Lit) independiente del framework: se carga con una sola etiqueta <script type="module">, pesa unos 18 KB gzip y no necesita servidor de mapas. Configúrelo visualmente en el Estudio de mapas →

02. Cuándo usarlo y cuándo no

✔ Usar para
Indicadores por municipio o subregión, presencia territorial, rutas y conexiones, tableros y presentaciones. Funciona sin servidor de mapas, sin internet de terceros y es imprimible.
✘ No usar para
Mapas con calles, ruteo o geolocalización fina (se hará con MapLibre en una fase posterior), ni para datos por vereda (aún no hay geometría oficial).

  mapa.datos = { '47001': 120, '47189': 80, '47980': 45 };          // código DIVIPOLA → valor

Angular (CUSTOM_ELEMENTS_SCHEMA)
// index.html:  <script type="module" src="https://TU-HOST/manual_de_marca/cdn/v1/gob.js"></script>
import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';

@Component({
  selector: 'app-mapa', standalone: true, schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `<gob-mapa-magdalena modo="coropleta" etiquetas="nombres"

  datos = { '47001': 120, '47189': 80 };
  alClic(e: Event) { console.log((e as CustomEvent).detail); }
}
React / Next.js
'use client'; // Next.js: solo cliente
import { useEffect, useRef } from 'react';

export default function Mapa({ datos, onMunicipio }) {
  const ref = useRef(null);
  useEffect(() => { import(/* webpackIgnore: true */ 'https://TU-HOST/manual_de_marca/cdn/v1/gob.js'); }, []);
  useEffect(() => {
    const el = ref.current; if (!el) return;
    el.config = { modo: 'coropleta', datos };
    const h = (e) => onMunicipio?.(e.detail);
    el.addEventListener('gob-municipio-click', h);
    return () => el.removeEventListener('gob-municipio-click', h);
  }, [datos]);
  return <gob-mapa-magdalena ref={ref} etiquetas="nombres" />;
}

Origen y licencia

Los códigos son DIVIPOLA del DANE y la geometría es el Marco Geoestadístico Nacional (MGN) 2024 del DANE; ambos son datos abiertos (citar «DANE»). Las subregiones son la agrupación usada en las presentaciones del equipo y deben validarse con Planeación. Detalle, fechas y pasos para regenerar en packages/datos/LICENCIAS.md.

08. Integración con una API NestJS

La llave siempre es el código DIVIPOLA, nunca el nombre del municipio. Formato de respuesta recomendado: { data: [{ codigo, valor }], meta }.

API NestJS → mapa
// NestJS + Prisma (PostgreSQL/PostGIS): indicador agrupado por código DIVIPOLA
@Controller('indicadores')
export class IndicadoresController {
  constructor(private prisma: PrismaService) {}

  @Get('casos-por-municipio')
  async casos() {
    const filas = await this.prisma.$queryRaw<{ cod_mpio: string; total: bigint }[]>`
      SELECT cod_mpio, COUNT(*) AS total FROM casos GROUP BY cod_mpio`;
    // Respuesta estándar: { data, meta }
    return { data: filas.map((f) => ({ codigo: f.cod_mpio, valor: Number(f.total) })), meta: { total: filas.length, actualizado: new Date().toISOString() } };
  }
}

// Frontend (cualquier framework)
const { data } = await fetch('/api/indicadores/casos-por-municipio').then((r) => r.json());
mapa.datos = Object.fromEntries(data.map((d) => [d.codigo, d.valor]));   // el código es la llave, nunca el nombre

09. Accesibilidad

  • Cada municipio es un botón enfocable (Tab, Enter/Espacio) con aria-label «Municipio, valor» y aria-pressed cuando está seleccionado.
  • Alternativa en texto: tabla oculta visualmente con código, municipio, subregión y valor para lectores de pantalla.
  • Foco visible, tooltip también al enfocar con teclado, y prefers-reduced-motion desactiva todas las animaciones.
  • El zoom con rueda requiere Ctrl/⌘ para no interferir con el desplazamiento de la página; hay botones + − ⌂.
  • La información nunca depende solo del color: leyenda, etiquetas y tooltip repiten los valores. Impresión: imprimir() o Ctrl+P ocultan los controles.
