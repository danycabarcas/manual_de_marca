Comprobar si hay una versión nueva

Comprobar versión
// ¿Su proyecto tiene la última versión? (opcional, para desarrollo)
import('https://cdn.jsdelivr.net/gh/danycabarcas/manual_de_marca@main/cdn/v1/gob.js').then(async () => {
  const actual = window.gob?.version;                      // versión que está cargando su página
  const ult = await fetch('https://cdn.jsdelivr.net/gh/danycabarcas/manual_de_marca@main/cdn/v1/version.json', { cache: 'no-store' }).then((r) => r.json());
  if (actual !== ult.version) console.warn(`gob-* ${actual} → disponible ${ult.version}: ${ult.novedades}`);
});

v0.6.1 2026-11-17

  • Arreglo Íconos SVG sin tamaño en las pantallas de acceso (p. ej. la flecha de «Volver a iniciar sesión» se veía gigante): ahora todo ícono dentro de .mg-auth tiene un tamaño por defecto (1.15 rem).
    ➜ Qué hacer: Nada: llega con gob.css. Si copió el login, agregue svg { width: 1.15rem; height: 1.15rem } dentro de su contenedor o actualice gob.css.

v0.6.0 2026-11-17

  • Nuevo Sistemas de solicitudes y administración (8 pantallas): registrar solicitud con asignación por tarjetas, consultar con filtros y estados, dashboard de recepción y de control con KPI y semáforo, entrega de respuestas, bitácora con línea de eventos, usuarios y matriz de roles y permisos.
    ➜ Qué hacer: Use los demos Solicitudes y administración.
  • Nuevo Clases nuevas del panel: mg-kcard (KPI con ícono), mg-sem, mg-opt/mg-optlist (opciones tipo tarjeta), mg-matriz, mg-caso/mg-evento, mg-usr/mg-rol, mg-codigo, mg-st, mg-efec, mg-cnt, mg-perfil y títulos de grupo en el menú (mg-nav__grp).
    ➜ Qué hacer: Nada: llegan con gob.css.
  • Cambio El menú lateral admite grupos con color y una tarjeta de perfil; la barra superior acepta el nombre de cada aplicación.

v0.5.1 2026-11-17

  • Arreglo CDN desde otros sitios (CORS): cargar gob.js, las fuentes o los datos desde otro origen (p. ej. localhost:4200 o una app en otro dominio) fallaba porque el servidor oficial no envía Access-Control-Allow-Origin. El código que genera el manual ahora usa la URL pública con CORS de jsDelivr: https://cdn.jsdelivr.net/gh/danycabarcas/manual_de_marca@v0.5.1/cdn/v1/.
    ➜ Qué hacer: Cambie en sus proyectos la base https://manualdemarca.magdalena.gov.co/cdn/v1/ por la de jsDelivr (o use la copia local). Ver CORS.

v0.5.0 2026-11-17

  • Nuevo Módulo de acceso: login con el modelo GEDIS (panel de marca + tarjeta con «la línea»), recuperar contraseña, nueva contraseña con fortaleza, verificación en dos pasos (OTP), registro y estados de acceso. Clases mg-auth*, mg-social, mg-fl, mg-otp, mg-fuerza.
    ➜ Qué hacer: Reemplace sus logins por el esqueleto de Demos → Acceso.
  • Nuevo Panel de gestión (diseño «Convocatorias»): barra superior con la línea, menú lateral claro y sticky, píldora de sección, tarjetas, listados, tablas con estados, pestañas y formularios. Clases mg-shell*, mg-panel*, mg-nav, mg-conv, mg-tbl, mg-chip, mg-dot…
    ➜ Qué hacer: Use los demos Panel como estructura de las aplicaciones internas.
  • Nuevo Catálogo de UI: acordeones (base, tarjetas, flush), pestañas (línea, píldora, segmentada, vertical) y formularios con etiqueta flotante.
  • Nuevo Demos de acceso y panel: 6 casos de acceso + 6 pantallas del panel, con la guía de cómo conectar el login al backend (401/423/429…).
  • Cambio El diálogo «Sin permisos» usa el azul de marca en su botón (antes naranja). Tipografía Montserrat en toda la interfaz.
    ➜ Qué hacer: Si tenía un botón naranja de aceptar, use mg-btn (azul).
  • Cambio Compatibilidad: los estilos de base (.mg-base) pasaron a especificidad cero; los controles sin clase vencen al «preflight» de Tailwind; nuevo gob.layer.css para Tailwind v4 / PrimeNG con capas.
    ➜ Qué hacer: Con Tailwind v4 cargue gob.layer.css primero. Ver compatibilidad.
  • Cambio Etiquetas del menú lateral oscuro (mg-sidebar__label) con mayor contraste (accesibilidad AA).
  • Docs Nueva guía para agentes de IA, página de compatibilidad, y esta página de novedades con version.json.

Anuncio v0.6.1
📣 Actualización del sistema de diseño de la Gobernación (v0.6.1)

Ya está disponible la versión 0.6.1 de los componentes y el manual de marca: https://manualdemarca.magdalena.gov.co/novedades.html

Lo nuevo:
• Login y casos de acceso (recuperar contraseña, 2 pasos, registro, estados) con el modelo GEDIS.
• Panel de gestión con menú lateral fijo, tarjetas, listados y tablas.
• Acordeones, pestañas y formularios con etiqueta flotante.

Qué debe hacer cada uno:
1) Si usa el CDN: use la URL con CORS https://cdn.jsdelivr.net/gh/danycabarcas/manual_de_marca@v0.6.1/cdn/v1/ (el dominio https://manualdemarca.magdalena.gov.co aún no permite cargarlo desde otros sitios). Cambie @v0.6.1 cuando quiera subir de versión.
2) Si tiene copia local (zip): descargue https://manualdemarca.magdalena.gov.co/dist/downloads/gob-cdn-v1.zip y reemplace su carpeta cdn/v1.
3) Si copió envoltorios o plantillas: revise la sección «Cómo actualizar» en la página de novedades.
Para los logins nuevos use el esqueleto de https://manualdemarca.magdalena.gov.co/demos/index.html#acceso
