Demos y plantillas

Páginas completas para copiar: login y casos de acceso, panel, trámites, territorio, mesa de ayuda, portal y catálogo de UI.

Plantillas completas hechas con los componentes gob-* y las clases mg-* (sin AdminLTE ni Bootstrap). En cada demo active «Guías de código» para ver y copiar cada sección, o copie la página entera. Los datos son ficticios.

01. Cómo usar un demo

  1. Abra el demo y pulse ‹/› Guías de código (abajo a la derecha): cada sección se enmarca con su nombre y un botón Copiar sección.
  2. O use ⧉ Copiar página / ⬇ .html: las rutas se vuelven absolutas y funciona pegado en cualquier sitio.
  3. Todo requiere solo gob.css (y gob.js si usa componentes gob-* o toasts). Sin internet: gob-cdn-v1.zip.
  4. En Angular/React/Next use el mismo HTML dentro de su plantilla (ver frameworks): las clases no dependen del framework.

Conectarlo con el backend

Conectar con su backend
// Mapa de respuestas del servidor → estado de la interfaz (use los mismos textos genéricos en todo el sistema)
async function ingresar(correo: string, clave: string) {
  const r = await fetch('/api/auth/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, credentials: 'include', body: JSON.stringify({ correo, clave }) });
  if (r.ok) {
    const { requiere2fa } = await r.json();
    return location.href = requiere2fa ? '/verificacion-2fa' : '/panel';          // 200 → panel (o paso 2)
  }
  switch (r.status) {
    case 401: return mostrar('error', 'Correo o contraseña incorrectos.');         // genérico: no diga cuál falló
    case 423: return location.href = '/acceso/bloqueada';                           // cuenta bloqueada → estados-acceso (Bloqueada)
    case 429: return mostrar('warn', 'Demasiados intentos. Espere unos minutos.');  // límite de tasa
    case 403: return location.href = '/acceso/sin-permiso';                         // sin permiso
    case 503: return location.href = '/acceso/mantenimiento';                       // mantenimiento
    default:  return mostrar('error', 'No pudimos procesar la solicitud. Intente de nuevo.');
  }
}
// mostrar(tipo, texto): asigne texto a .mg-auth__msg, cambie la clase mg-auth__msg--<tipo> y quite [hidden].

Seguridad y buenas prácticas

  • Mensajes genéricos: «correo o contraseña incorrectos» y, en recuperación, la misma respuesta exista o no la cuenta (evita enumerar usuarios).
  • Autocompletado correcto: autocomplete="username", current-password, new-password, one-time-code para que los gestores de contraseñas funcionen.
  • Límite de intentos y bloqueo siempre en el servidor; la interfaz solo lo refleja (los demos lo simulan en el cliente).
  • Tokens y códigos: enlace de restablecimiento de un solo uso y corta vida (30 min); OTP de 5–10 min; HTTPS y cookies HttpOnly; Secure; SameSite.
  • Accesibilidad: etiquetas visibles, role="alert" en errores, foco al primer campo con error, botón de ojo con aria-pressed. Probado con axe (WCAG 2.1 AA).
  • Datos de prueba de los demos: demo@magdalena.gov.co / Demo1234 (login) y 123456 (2FA). Son ficticios y solo existen en el navegador.
