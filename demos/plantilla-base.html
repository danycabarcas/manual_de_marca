Cómo usar este demo como plantilla (clic para ocultar)
  1. Pulse «‹/› Guías de código» (abajo a la derecha): cada sección se enmarca con su nombre y un botón Copiar sección.
  2. O use «⧉ Copiar página» / «⬇ .html» para llevarse la página completa. Las rutas relativas se convierten en absolutas (https://su-sitio/…), así funciona pegada en cualquier sitio.
  3. Toda página necesita solo dos líneas en el <head>: gob.css y gob.js (están en el <head> de este archivo, marcadas con ①). Sin internet: descargue gob-cdn-v1.zip.
  4. Esta es la plantilla mínima: copie la página completa y empiece. Está comentada paso a paso (① a ⑦).

Componentes usados: mg-hero, gob-alerta, gob-kpi, gob-tabla, gob-grafica, gob-mapa-magdalena, gob.toast(). Los datos son ficticios (cdn/v1/datos/ejemplo-*.json); en producción cámbielos por su API.
