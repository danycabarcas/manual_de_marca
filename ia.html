Para agentes de IA

Instrucciones y skill para que cualquier agente de IA use los componentes gob-* sin explicaciones.

Para que cualquier agente de IA (Claude, ChatGPT, Copilot, Cursor, Gemini…) use estos componentes sin que tenga que explicárselos: un archivo Markdown con todo lo necesario (instalación, reglas, catálogo, flujo de trabajo) que el agente lee y aplica como si fuera una skill.

01. Opción rápida: pegue esta instrucción

Sirve en cualquier chat o agente con acceso a internet:

Instrucción
Lee https://manualdemarca.magdalena.gov.co/docs/ia/gob-componentes.md y úsalo como guía obligatoria para construir la interfaz: usa los componentes gob-* y las clases mg-*, y parte del demo más parecido de https://manualdemarca.magdalena.gov.co/demos/. Lo que necesito: …

02. Para que lo use siempre en su proyecto

  • Cualquier agente: copie AGENTS.md a la raíz del proyecto (también sirve como CLAUDE.md, .cursorrules o .github/copilot-instructions.md).
  • Claude Code / Claude: instale la skill — copie la carpeta gob-componentes/ (contiene SKILL.md) a ~/.claude/skills/ (global) o a .claude/skills/ del proyecto. Se activa sola cuando pidan pantallas para la Gobernación.
  • Rastreadores y agentes web: llms.txt indexa toda la documentación en el formato estándar.
⬇ Skill + AGENTS.md (.zip)Ver la guía (.md)llms.txt

03. Qué contiene la guía

  • Las dos líneas de instalación y cómo autohospedar sin internet.
  • Reglas de oro (propiedades vs. atributos, eventos, mensajes, colores, licencias).
  • Catálogo de los componentes con sus atributos y eventos clave, y las especificaciones de los widgets del dashboard.
  • Formularios nativos y clases mg-*.
  • Flujo recomendado: partir de un demo, copiar el ejemplo más cercano, validar.
  • Errores frecuentes.

La guía se regenera con cada versión del sitio, así que siempre refleja los componentes publicados.
